## 指南中的关键硬性要求

- 选题可采用：指定 40 题、适度改题或自主选题；本项目拟优先采用**第 29 题适度改题**。
- 精读 **15–25 篇**真实可查的论文：**CCF B 类及以上期刊、CCF C 类及以上会议**；近五年文献原则上不少于 **60%**；预印本/白皮书可作背景，不计入精读篇数。
- 报告结构：选题依据与分类综述约 **500 字**；每篇论文剖析 **300–500 字**；整体深度综述与展望约 **2500 字**。
- 提交成品为**中文版 .docx Word**；不得以 PDF/Markdown 或英文综述替代。
- 学术规范：AI 可辅助检索、梳理与润色，但不得虚构文献、数据或推导，**不得直接用 AI 生成综述主体段落**；方法评价及综合分析须由作者独立完成。
- 课程模板及封面格式不得擅改，交付前需按原始指南再次核对。

## 工作原则

**先确定选题边界，再核验文献，最后以作者的独立阅读和分析撰写正文。** 本仓库 Markdown 文件仅作为过程记录，不等同于可直接提交的课程综述。
