# [13] HFuzzer: Testing Large Language Models for Package Hallucinations via Phrase-based Fuzzing

paper_id: doi:10.1109/ASE63991.2025.00225。Yukai Zhao, Menghan Wu, Xing Hu, Xin Xia；ASE2025，2746–2758。[DOI](https://doi.org/10.1109/ASE63991.2025.00225)；[arXiv:2509.23835](https://arxiv.org/abs/2509.23835)；[工件](https://github.com/YukZhao/HFuzzer)。本地13页全文，2026-11-17核验方法、主要结果和局限，未复现实验。

## 方法与分母

从真实包描述抽取短语种子，组合生成开发任务，向被测模型查询代码及依赖信息，通过包仓库/API判断候选包，依照发现的新幻觉包和反馈动态调整种子权重，并扩充池。p3–5说明流程。它主要是输入生成和模型测试框架，不能称作对任意现成代码的通用漏洞检测器。

p5–6实验：Python，9种模型分别作为tester和target形成81组合，每轮上限1,000轮；tester温度0、target0.7。初始取SourceRank前100 Python包描述。PHR定义是含幻觉包的响应数/总响应数，而非幻觉包名数/所有包名出现次数。

## 2.60与2.36已消歧

- p6表II：独特幻觉包数量的平均倍率为2.60（相对作者适配的GPTFuzzer-A）。不是PHR提升2.60倍，也不能据此算自然任务发生率。
- p7图5及正文：基于DBSCAN聚类数加噪声点数的Diversity Index平均倍率2.36，是任务多样性。两者都正确，指标不同。
- p7表III相关复跑仅选3个target，平均倍率3.02；不能混成全81组合2.60的重复实验数。
- p8附加GPT-4o实验：发现46个独特幻觉包，其中11是其他语言的包；区分代码import错误与安装指令错误，如import pywt与安装PyWavelets的映射问题。

## 局限

p10 §V.F：主要Python；正则抽取准确性和采样策略覆盖有限。独立判断：包名判定及包仓库随时间变化亦需控制。p7还讨论Qwen2.5-Coder过度拒绝导致低PHR；低PHR可能来自不生成代码。独立判断：种子主动诱发分布不能代表真实用户请求发生率；跨语言包、模块名与分发包名、占位符和用户自建模块应分开处理，避免把每个不存在的名字都当成恶意依赖。

## Word摘要卡

- 研究问题：怎样系统构造任务以发现LLM依赖包幻觉？
- 意义：为供应链依赖风险提供主动测试输入和可重放触发案例。
- 方法：短语种子组合、模型反馈权重更新、包仓库核验与种子扩充。
- 实验与页码：p6表II独特幻觉包平均为GPTFuzzer-A的2.60倍；p7图5任务多样性为2.36倍；p8附加GPT-4o找到46个独特幻觉包。
- 局限：Python与适配基线范围有限，主动诱发率不等于自然使用风险率。
- 作者写作任务：自行说明输入测试框架、输出判别器与恶意依赖检测器之间的区别。
