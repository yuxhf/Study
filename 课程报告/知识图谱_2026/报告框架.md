# 知识图谱课程报告：新框架（4 KG + 1 Memory）

## 拟题
**面向大语言模型的知识图谱构建、检索与推理技术研究——以 GraphRAG 与长期记忆为例**

## 一、引言：知识图谱为什么能增强 LLM？
- 传统语言模型的参数知识更新慢，纯文本 RAG 的片段检索不直接表达实体与关系链。
- KG 用实体、关系、来源与结构约束组织知识，支持结构化查询和多跳检索。
- 主问题：**图如何构建、如何找到相关子图、如何推理、如何延伸为长期知识利用？**

## 二、知识图谱核心技术（4 篇主论文）
**第 1 篇 — SAC-KG（ACL 2024）：知识图谱构建**
- 从领域语料出发，Generator / Verifier / Pruner 生成多层 KG，并检验三元组质量。
- 对比问题：构建精度、幻觉、图谱规模与人工审核成本。

**第 2 篇 — KGP（AAAI 2024）：跨文档关系图与图遍历检索**
- 从文档中的 passage 和结构关系建立图，LLM 图遍历 Agent 逐步收集证据。
- 对比问题：跨片段关联、检索延迟与路径可解释性。

**第 3 篇 — G-Retriever（NeurIPS 2024）：文本属性图中的 GraphRAG**
- 从大规模图选择与问题相关的图结构，使用 Prize-Collecting Steiner Tree 形式化检索。
- 对比问题：图大小、检索质量、生成幻觉与 token 预算。

**第 4 篇 — FastToG（AAAI 2025）：知识图谱社区检索与多跳推理**
- 在 KG 上以社区为单位推理，采用社区发现、粗细两级剪枝以及 Community-to-Text。
- 对比问题：节点/路径 vs 社区粒度、推理深度、效率与解释性。

## 三、Memory 拓展（仅 1 篇）
**第 5 篇 — HippoRAG 2（ICML 2025）**
- 保留原组会汇报中 HippoRAG 2 的重点：PPR 图关联、篇章与知识的结合、事实记忆和联想记忆。
- 以“**图结构能否帮助跨次查询关联、重用已有知识**”作为应用讨论，不将 Memory 管理或 RL 作为课程主线。

## 四、五篇论文对比分析
| 方法 | 主要对象 | 图/索引结构 | 查询或推理机制 | 需要检验的局限 |
|---|---|---|---|---|
| SAC-KG | 领域语料 | 实体关系多层 KG | 迭代生成-验证-剪枝 | 错误三元组传播，构建成本 |
| KGP | 多文档段落与文档结构 | 跨段落/结构关系图 | LLM Agent 图遍历 | 图质量和遍历效率 |
| G-Retriever | 文本属性图 | 查询相关子图 | Steiner Tree 优化与 LLM | 大图可扩展性，图抽取精度 |
| FastToG | 结构化知识图谱 | 图社区 | 社区发现与分级剪枝 | 社区划分误差与关系损失 |
| HippoRAG 2 | 文本知识与外部长期知识 | 关联图与文段索引 | PPR+LLM 检索 | 事实记忆与复杂关联的权衡 |

注意：五篇论文的任务、数据集、模型和评价指标不完全一致；**不得把论文中的结果直接按一个指标排序**。此处局限列为需在精读时检验的分析角度，不是已实证的否定结论。

## 五、结合本人科研方向的新思路（简要）
拟议方向：**可追溯的知识图谱增强检索与经验复用**。
- 利用 SAC-KG 思路提取实体/关系，并保留证据来源；
- 借鉴 KGP、G-Retriever、FastToG 进行查询相关图遍历、子图或社区级检索；
- 以 HippoRAG 2 为例，讨论跨任务的知识重用；
- 可点到 Complementary RL 的经验—策略协同学习，但**不把它写成第六篇或主线**。
- 研究想法：如何在保持关系可追踪的前提下，减少无关检索并适应动态任务；尚未开展实验，不能填入虚构增益。

## 六、结论与待补充部分
- 图谱构建质量是检索和推理的基础；
- 图遍历/子图检索/社区搜索是不同粒度的 GraphRAG 组织选择；
- 长期记忆是知识图谱能力的一种应用，不是本次报告的中心。
