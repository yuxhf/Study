# 知识图谱课程报告：简要框架（待补充）

**拟题：面向大语言模型智能体的知识图谱增强记忆技术研究**

## 一、研究背景
- LLM Agent 处理长时、多轮任务时面临记忆丢失、跨文档关联困难、记忆维护不足。
- 传统向量 RAG 与图结构记忆的差异：相似度召回 vs 关系连接/关联检索。
- 引出课程核心：**如何以知识图谱组织、检索、更新 Agent Memory？**

## 三、论文对比分析
建议使用“记忆写入—组织—检索—更新—学习”作为统一分析轴。

| 方法 | 图谱/结构 | 检索机制 | 动态记忆 | 学习策略 | 主要关注点 |
| --- | --- | --- | --- | --- | --- |
| HippoRAG | 无模式知识图谱 | Personalized PageRank 关联检索 | 离线知识索引 | 非策略 RL | 关系检索与跨文档多跳 |
| HippoRAG 2 | 图结构+篇章关联 | PPR 与 LLM 结合 | 非参数化新知识纳入 | 非策略 RL | 事实回忆、意义理解与关联检索 |
| A-Mem | 动态链接的记忆网络 | 关联记忆检索 | 新记忆促进旧记忆更新 | Agent 驱动组织 | Zettelkasten 启发的动态链接 |
| G-Memory | insight/query/interaction 三层图 | 双向层级检索 | 协作经验渐进吸收 | 不以 RL 为核心 | 多 Agent 经验组织 |
| Memory-R1 | 外部记忆库（**不是以 KG 为核心**） | Answer Agent 选择与利用 | ADD/UPDATE/DELETE/NOOP | RL 学习管理与利用 | 可学习的记忆管理 |

## 四、结合本人研究：从“图结构记忆”到“经验与策略共同演化”
**关联阅读**：Complementary Reinforcement Learning（2026，arXiv:2603.17621，*不计入 5 篇 CCF A*）。

参考组会报告中“经验提取器 + Actor 共同演化”的视角：
1. 图谱记忆负责保存实体、事件、来源和经验关联；
2. 检索策略按当前任务取回相关子图及证据，而非仅靠向量相似度；
3. 记忆更新策略判断保留、补充、合并与删除；
4. 可讨论“记忆质量与策略表现是否能协同优化”，但它是**研究设想**，不写成已完成实验。

建议留一个小例子：长时 Agent 任务中，某次失败经验经图谱关联被下一次检索并影响决策。明确区分**记忆组织/检索的贡献**与**RL 的策略学习贡献**。

## 五、总结与展望
- 知识图谱解决的关键问题：结构化表示、跨记忆关联、多跳检索、关系可解释性。
- 尚需研究的关键问题：图谱构建成本、噪声传播、时间一致性、动态更新、检索和策略的联合学习。
- 与本人工作相接：经验图谱能否提升可复用性、降低冗余记忆、改善长期任务表现？
