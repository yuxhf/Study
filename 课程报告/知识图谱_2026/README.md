# 2026 年《知识图谱》课程报告

## 选题（讨论版）
**面向大语言模型智能体的知识图谱增强记忆技术研究**
（Knowledge Graph-Enhanced Memory for Large Language Model Agents）

本课程以 **Agent Memory + 知识图谱 + RAG** 为主线，不与“网络与信息安全”课程强行合并。基于 2026-11-08 的 Agent Memory 组会汇报扩展，保留独立的论文与提交内容。

## 课程要求
- **5 篇 CCF A 类、同一主题的知识图谱方向论文全文翻译**；英文论文标题保留原文，参考文献不翻译（据课堂照片及本人澄清）。
- 5 篇论文的横向对比分析。
- 结合本人研究方向提出新思路；Complementary RL 作为非计数的额外关联阅读，不替代五篇 A 类论文。
- **2026-11-27（周五）**，第 13 周最后一次课堂；仅纸质版，双面打印。
