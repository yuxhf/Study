# 研究生课程报告

本目录用于统一管理各门研究生课程的课程报告，**一门课程一个独立子文件夹**，避免不同课程的选题、文献、草稿与最终提交版混放。

## 课程索引

| 课程 | 学年 | 目录 | 状态 |
| --- | --- | --- | --- |
| 网络与信息安全 | 2026 | [网络与信息安全_2026](./网络与信息安全_2026/) | 选题与文献准备中 |
| 知识图谱 | 2026 | [知识图谱_2026](./知识图谱_2026/) | Agent Memory + KG 选题框架与 5 篇 A 类论文已整理 |

两门课分别管理；知识图谱聚焦 Agent Memory，不强制与网络安全选题重合。

## 每门课程建议结构

- `README.md`：课程要求、进度、文件导航
- `选题与构建计划.md` 或 `报告框架.md`：题目、范围、结构与任务安排
- `文献池.md` 或 `文献清单.md`：候选文献、等级与发表信息的核验状态
- `drafts/`：本人撰写的工作草稿（按需建立）
- `submission/`：最终提交文件（按需建立）

> Git 不保存空文件夹，因此仅在有实际材料时建立对应子目录。课程之间独立管理，默认不修改仓库现有其他学习资料。
